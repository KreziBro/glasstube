# GlassTube

Концепт современного веб-интерфейса видеохостинга в стиле **Glassmorphism** (эффект матового стекла), вдохновленный дизайном YouTube. Реализован в виде легковесного автономного Single-Page приложения на чистом HTML, CSS и Vanilla JavaScript без внешних фреймворков и сборщиков.

🔗 **[Демо онлайн](https://krezibro.github.io/glasstube/)**

## Особенности

* **Glassmorphism дизайн**: Полупрозрачные панели, размытие фона (`backdrop-filter`), мягкие блики, объёмные градиентные пятна и плавные тени
* **Тёмная и светлая тема**: Автоматическое определение системной темы и быстрое ручное переключение кликом по иконке в шапке
* **Интерактивный плеер**: Режим просмотра видео с динамическим обновлением информации (название, автор, счетчики, рекомендации)
* **Диалог «Поделиться»**: Модальное окно шаринга с быстрым копированием ссылки, чекбоксом таймкода и шорткатами соцсетей
* **Адаптивность**: Корректное отображение на смартфонах, планшетах и широких мониторах (с поддержкой `safe-area-inset`)
* **Zero Dependencies**: Никаких сторонних библиотек, сборщиков и npm-зависимостей — файл самодостаточен и весит меньше 25 КБ

## Стек

* **HTML5** (семантическая верстка, инлайновые SVG-иконки, атрибуты доступности)
* **CSS3** (CSS-переменные для тем, Flexbox, Grid, стеклянный морфизм, анимации)
* **Vanilla JavaScript** (управление плеером, смена тем, поиск и фильтрация)
* **Google Fonts** (Onest, Unbounded)

## Запуск

### Локально
Достаточно открыть `index.html` в любом современном браузере:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Деплой
Так как это чистый статический файл, его можно мгновенно развернуть на любой платформе:
* **GitHub Pages** (Settings → Pages → ветка `main`)
* **Vercel** / **Netlify** / **Cloudflare Pages**
* Любой веб-сервер (Nginx, Caddy, Apache)
